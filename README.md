# Tindahan POS

A cloud point-of-sale for sari-sari and variety stores, for Windows (64-bit).

## Download

**[Download Tindahan POS for Windows](https://github.com/jlsusvilla01-cloud/tindahan-pos-download/releases/latest/download/Tindahan-POS-Setup.exe)** (about 78 MB)

## Install

1. Open the downloaded file.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. The installer isn't digitally signed yet, so Windows shows this warning.
3. Open **Tindahan POS** from your Desktop.
4. Click **Create an account** and enter your store name. Use your real email, because that's how you reset your password.

Once installed, the app updates itself. When a new version is ready, click **Restart to update** at the top of the screen.

The first login on each computer needs internet. After that, selling works offline, and sales upload when the connection returns.
